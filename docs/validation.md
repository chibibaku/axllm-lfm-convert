# 動作確認と制限

対象モデルはLFM2.5-2.6B、変換ホストはUbuntu 24.04 x86_64、推論先はAX8850です。

これまでの動作確認では、CPU校正から48グラフの生成とFP32／BF16パッケージ作成まで完了しました。
実機ではFP32 disk、BF16 disk、BF16 CMMで日英の複数ターン会話、会話内容の保持、
`/reset` による初期化、生成の正常終了を確認しています。これらは今回の整理前の実装での結果です。

校正時には元のTransformers実装と変換用演算を比較します。
今回の整理で変更した取得・途中再開・パッケージ処理は、単体テストで確認します。
CPUでの全モデル再変換と実機試験は、今回の整理後には再実行していません。

既知の制限:

- コンテキスト長の設定上限は131,072トークンです。全長の自然文処理、長文品質、長時間の連続生成は未検証です。
- コンパイラ内部の全演算精度・全重みの量子化方式は確認していません。
- FP32 KV／BF16 KVの定量的な品質比較は未実施です。
- CUDAでの校正と、CUDAを使う全工程の再生成は検証範囲が異なります。今回の整理後はいずれも再実行していません。
- GitHub Actionsは軽量な単体テストのみを実行します。モデル全体の変換や実機試験は行いません。

公開モデルリポジトリにはモデルカードとプロファイルのみを掲載し、モデル本体は含めません。
